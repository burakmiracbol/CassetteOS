# LVGL Pro UI Baseline

This folder now includes a starter XML structure mapped to current app states in `Model.h` and `Ui.cpp`.

## Required Project Files

- `project.xml` (target display/project metadata)
- `globals.xml` (shared styles/constants/fonts/images/subjects)
- `file_list_gen.cmake` and `component_lib_list_gen.cmake` (included by `CMakeLists.txt`)
- `ui_project_stub.c` (temporary source so CMake target is never empty)

## Screens

- `screens/screen_boot.xml`
- `screens/screen_now_playing.xml`
- `screens/screen_search.xml`
- `screens/screen_library.xml`
- `screens/screen_favorites.xml`
- `screens/screen_screensaver.xml`
- `screens/screen_error.xml`

## Reusable Building Blocks

- `components/top_status.xml`
- `widgets/action_button/widget.xml`

## About `.c/.h` Files

- In Editor-first flow, you mainly edit XML files.
- `.c/.h` files are generated by LVGL Editor export (e.g. `*_gen.c`, `*_gen.h`).
- Optional manual `.c/.h` wrappers are used only when you need custom logic/hooks.
- Before export, this project keeps a minimal `ui_project_stub.c` to satisfy CMake.
